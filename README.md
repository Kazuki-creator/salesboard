# SalesBoard

**React × TypeScriptで開発した営業・顧客管理システム（CRM）**

## 概要

SalesBoardは、法人・個人の顧客情報や商談状況、営業活動を一元管理するためのWebアプリケーションです。

経営コンサルティング事業での活用を想定し、顧客管理・商談管理・活動履歴・売上分析など、営業活動に必要な情報を可視化することを目的として企画・開発しました。

実際の事業運営経験を活かし、業務課題の整理から機能設計、フロントエンド開発まで取り組んだ自社開発プロジェクトです。

## 開発背景

営業活動では、顧客情報や商談状況、対応履歴などの情報が分散すると、進捗の把握や次のアクションの判断が難しくなります。

そこで、顧客との関係性や商談の進捗、日々の営業活動を一元的に把握できるシステムとしてSalesBoardを企画しました。

法人営業・個人営業の両方に対応できる汎用的なCRMを目指しています。

## 主な画面・機能

### ダッシュボード

営業活動や商談状況を一覧で確認するための画面です。

### 顧客管理

法人・個人の顧客情報を管理するための画面です。

### 商談管理

商談情報や進捗状況を管理するための画面です。

### 活動管理

顧客への対応や営業活動を整理・確認するための画面です。

### レポート

営業状況や売上に関する情報を可視化するための画面です。

## 開発で重視した点

**1. 実際の業務課題をもとにした機能設計**

経営コンサルティング事業での経験をもとに、顧客管理・商談管理・活動管理など、営業現場で必要になる機能を整理しました。

**2. 法人・個人の両方を想定したCRM設計**

特定の業種に限定せず、さまざまな営業活動に応用できるシステムを目指しました。

**3. React・TypeScriptによるフロントエンド開発**

ReactとTypeScriptを採用し、複数の業務画面を持つWebアプリケーションの開発に取り組みました。

**4. ビジネスとエンジニアリングの両面からの開発**

自身の事業運営経験を活かし、機能の実装だけでなく、実際の業務でどのように活用されるかを考慮して設計しました。

## 開発目的

営業活動の効率化と情報の一元管理を目的とした自社開発プロジェクトです。

また、TypeScript・Reactを用いた複数画面のWebアプリケーション開発を通じて、業務要件の整理、画面設計、機能実装などの実践的なスキルを高めることも目的としています。
